## 字体使用说明

### 中文字体搭配建议
- **学术论文标准搭配**：Adobe Song Std (正文) + Source Han Serif SC Heavy (粗体)
- **系统字体搭配**：SimSun (正文) + SimHei (标题)
- **开源字体完整搭配**：见 `style/jluthesis2023.sty` 中的开源字体设置

### 英文字体搭配建议
- **标准学术搭配**：Times New Roman (衬线) + Arial (无衬线) + Courier New (等宽)
- **开源替代搭配**：Nimbus Roman (衬线) + Nimbus Sans (无衬线) + Nimbus Mono (等宽)

### LaTeX 中的字体调用
```latex
% 中文字体命令
{\song 宋体文字}
{\hei 黑体文字}  
{\kai 楷体文字}
{\fs 仿宋文字}
{\li 隶书文字}

% 英文字体命令
\textrm{衬线字体}
\textsf{无衬线字体}
\texttt{等宽字体}
```
